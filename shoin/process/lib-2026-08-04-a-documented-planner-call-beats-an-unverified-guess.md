# A documented planner call beats an unverified guess

**Principle:** A documented planner call beats an unverified guess.

**Why:** The guessed row for the researchify flow-map node failed the geometry audit on every candidate; the planner's documented alternative passed four independent audits and was placed. The guess carried no derivable evidence; the documented call did.

**When to apply:** contested placements, numbers, or geometry where evidence can be derived and audited.

**When not to:** trivial reversible choices where a quick try is cheaper than an audit.
